# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-09-06

### Added

- Cross-platform `localmedia` CLI
- Convert, CRF compression, target-size two-pass compression, resize, trim, audio extraction, metadata stripping, and batch conversion
- Tk desktop GUI for core local workflows
- Windows, macOS, and Ubuntu bootstrap guidance
- Unit tests and FFmpeg smoke test
- GitHub Actions CI
- Security, privacy, architecture, codec, troubleshooting, contribution, and licensing documentation
